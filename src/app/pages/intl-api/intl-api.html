The Intl API — Your Built-in Superpower

Forget external date libraries for formatting. Modern browsers ship with the Intl namespace — a powerful set of internationalization APIs that handle timezone conversions and locale-aware formatting natively.

Intl.DateTimeFormat is the star. It can display any Date in any timezone and any locale without mutating the original Date or importing anything.

Why Intl Matters

  • ✓ Zero dependencies — it ships with every modern browser and Node.js.
  • ✓ IANA-aware — it knows about DST rules, historical timezone changes, everything.
  • ✓ Locale-aware — different countries format dates differently. Intl handles it.
  • ! Angular's DatePipe does NOT use it. @angular/common ships its own locale data and contains zero references to Intl.DateTimeFormat. Its timezone parameter resolves a fixed offset, not an IANA name — see the Angular & Dates tab. For zone-aware display, reach for Intl directly.

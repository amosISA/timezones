Switching Timezones

You cannot find a timezone bug from inside a single timezone. Almost every one of them is invisible on the machine that wrote the code and obvious on a machine eight hours away — so being able to move your own clock in seconds is the single highest-leverage skill in this whole topic.

Below: the fast way (DevTools), the thorough way (your OS), the surgical way (the TZ variable), and how to pin it in tests so a regression cannot come back.

A complete debugging exercise

Chrome can emulate Cairo without changing your computer. Create a reusable location preset once, then switch the inspected page between your real environment and Egypt in seconds.

1. Add the Cairo preset
  1. 01 Open DevTools Settings with F1, select Locations, then click Add location.
  2. 02 Enter the values below and save the preset.
  3. 03 Open Sensors, select Cairo from Location, and reload this page.

2. Prove the override is active

The zone should be Africa/Cairo. The ISO instant does not change; only the local representation and offset do.

Test one variable at a time. Use ar-EG for a realistic Egyptian locale. Use es-ES with Africa/Cairo when you want to isolate timezone behavior without also changing number and date formatting.

To return to Spain, choose No override in Sensors or close DevTools and reload. The override is scoped to the inspected page; it does not change your operating system.

Which One Should You Use?

Poking at a bug

DevTools Sensors. Two keystrokes, scoped to one tab, undone by closing the panel. Nothing else comes close for a quick check.

Developing a feature

The TZ variable. Reproducible, committed in a script, and identical to what CI does. No system settings to remember to undo.

Reproducing a user report

The OS setting. The only one that exercises the whole stack the way the user's machine does — including anything outside the browser.

One habit worth building: before you call any date-handling work finished, flip to a zone on the other side of UTC and reload. It takes fifteen seconds and it catches the class of bug that otherwise gets found by a user in Auckland.
